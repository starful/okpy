## Effect snapshot

| | |
|--|--|
| Intervention | Allow players to skip or fast-forward the opening tutorial |
| Outcome | Day-1 retention rate |
| Effect | 4–11 percent relative increase |
| Confidence | `ab_test` |
| Context | Mobile F2P games, casual and mid-core, 2022–2025 |

### Sources

- [GameAnalytics — Onboarding](https://www.gameanalytics.com/blog/onboarding-best-practices)

## What changes

Skippable tutorials are often linked to a 4–11% relative improvement in day-1 retention versus forced onboarding.

## When this tends to work

- Conditions similar to: Mobile F2P games, casual and mid-core, 2022–2025
- You can measure `Day-1 retention rate` reliably
- The intervention is implemented consistently, not half-measured

## When to be careful

- Your audience or product differs materially from the cited context
- Compliance costs or second-order effects outweigh the lift
- Evidence label is **ab_test**—treat wide ranges as planning bands, not promises

## Practical takeaway

Use the cited range for prioritization and test design. Verify against your own data before scaling.
