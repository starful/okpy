## Effect snapshot

| | |
|--|--|
| Intervention | Introduce escalating daily login rewards with streak counter |
| Outcome | Daily active users (DAU) |
| Effect | 8–18 percent relative increase |
| Confidence | `estimate` |
| Context | Mobile F2P with sessions under 10 minutes, 2021–2025 |

### Sources

- [Deconstructor of Fun — Live ops](https://www.deconstructoroffun.com/)

## What changes

Daily streak systems are commonly cited for an 8–18% relative lift in DAU, with diminishing returns after week three.

## When this tends to work

- Conditions similar to: Mobile F2P with sessions under 10 minutes, 2021–2025
- You can measure `Daily active users (DAU)` reliably
- The intervention is implemented consistently, not half-measured

## When to be careful

- Your audience or product differs materially from the cited context
- Compliance costs or second-order effects outweigh the lift
- Evidence label is **estimate**—treat wide ranges as planning bands, not promises

## Practical takeaway

Use the cited range for prioritization and test design. Verify against your own data before scaling.
