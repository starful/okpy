## 効果のスナップショット

| | |
|--|--|
| 施策 | ヒーローの見出し・サブ見出しを、10語未満で成果（アウトカム）が伝わる表現に書き換える |
| 指標 | ランディングページの直帰率 |
| 効果 | 相対値で7〜14%の減少 |
| 確度 | `ab_test`（A/Bテストによる検証） |
| 対象範囲 | 有料流入のランディングページ、B2B・コンシューマー双方、2023〜2025年 |

### 出典

- [Unbounce — Landing page benchmarks](https://unbounce.com/average-conversion-rates-landing-pages/)

## 何が変わるのか

ファーストビューの価値提案（何が得られるページなのかを短時間で理解できる訴求）を明確にすると、有料流入のランディングページで直帰率が相対値で7〜14%低下することが多いと報告されている。

## この施策が効きやすい条件

- 対象範囲と近い条件（有料流入のランディングページ、B2B・コンシューマー、2023〜2025年）で運用している
- 「ランディングページの直帰率」を安定して計測できる
- 施策を中途半端にせず、一貫した形で実装できている

## 注意すべき点

- 自社のオーディエンスやプロダクトが、引用元の条件と大きく異なる場合
- 実装コストや副作用が、期待できる改善効果を上回る場合
- エビデンスラベルは **ab_test** であり、示された幅は「約束」ではなく「計画時の目安」として扱うべき

## 実務上の示唆

この数値レンジは、優先順位付けとテスト設計の参考値として活用するとよい。本番展開の前に、必ず自社データで検証すること。
