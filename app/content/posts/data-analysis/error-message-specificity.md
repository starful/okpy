## Effect snapshot

| | |
|--|--|
| Intervention | Replace generic errors with field-specific, actionable messages |
| Outcome | Successful form resubmission rate |
| Effect | 15–28 percent relative increase |
| Confidence | `study` |
| Context | Account creation and payment forms, English UI, 2022–2025 |

### Sources

- [Nielsen Norman Group — Error messages](https://www.nngroup.com/articles/error-message-guidelines/)

## What changes

Field-specific error copy is associated with a 15–28% relative improvement in users successfully fixing and resubmitting forms.

## When this tends to work

- Conditions similar to: Account creation and payment forms, English UI, 2022–2025
- You can measure `Successful form resubmission rate` reliably
- The intervention is implemented consistently, not half-measured

## When to be careful

- Your audience or product differs materially from the cited context
- Compliance costs or second-order effects outweigh the lift
- Evidence label is **study**—treat wide ranges as planning bands, not promises

## Practical takeaway

Use the cited range for prioritization and test design. Verify against your own data before scaling.
