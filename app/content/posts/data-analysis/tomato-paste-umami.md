## Effect snapshot

| | |
|--|--|
| Intervention | Sauté tomato paste 2–3 minutes until darkened before adding liquid |
| Outcome | Umami intensity rating in blind tests |
| Effect | 18–35 percent relative increase |
| Confidence | `study` |
| Context | Tomato-based pasta sauces, home cooks, blind panels |

### Sources

- [Serious Eats — Tomato paste](https://www.seriouseats.com/how-to-use-tomato-paste)

## What changes

Browning tomato paste before deglazing is commonly associated with 18–35% higher umami ratings versus raw paste addition.

## When this tends to work

- Conditions similar to: Tomato-based pasta sauces, home cooks, blind panels
- You can measure `Umami intensity rating in blind tests` reliably
- The intervention is implemented consistently, not half-measured

## When to be careful

- Your audience or product differs materially from the cited context
- Compliance costs or second-order effects outweigh the lift
- Evidence label is **study**—treat wide ranges as planning bands, not promises

## Practical takeaway

Use the cited range for prioritization and test design. Verify against your own data before scaling.
