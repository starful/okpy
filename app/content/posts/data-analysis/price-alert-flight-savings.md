## Effect snapshot

| | |
|--|--|
| Intervention | Set fare alerts 8–12 weeks ahead vs manual one-time search |
| Outcome | Fare paid vs initial search price |
| Effect | 5–15 percent relative decrease |
| Confidence | `estimate` |
| Context | Leisure routes tracked on Google Flights / Hopper, 2022–2025 |

### Sources

- [Hopper — Price prediction](https://hopper.com/)

## What changes

Price alerts are often associated with 5–15% lower fares versus buying at first search for flexible-date travelers.

## When this tends to work

- Conditions similar to: Leisure routes tracked on Google Flights / Hopper, 2022–2025
- You can measure `Fare paid vs initial search price` reliably
- The intervention is implemented consistently, not half-measured

## When to be careful

- Your audience or product differs materially from the cited context
- Compliance costs or second-order effects outweigh the lift
- Evidence label is **estimate**—treat wide ranges as planning bands, not promises

## Practical takeaway

Use the cited range for prioritization and test design. Verify against your own data before scaling.
