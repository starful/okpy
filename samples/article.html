AWS Lambda vs GCP Cloud Functions vs Azure Functions

イベント駆動の小さな処理を、サーバー管理なしで動かす代表サービスを、実務目線で比較します。

導入

いずれも「関数をアップロードしてトリガーで実行」というモデルですが、周辺エコシステムとコールドスタートの体感が大きく異なります。

機能別比較

観点 AWS Lambda GCP Cloud Functions Azure Functions
強み サービス連携の幅 GCPデータ基盤との統合 .NET / Microsoft 連携
料金感 実行時間 + リクエスト 世代・リージョンで差 プラン依存
運用 CloudWatch Cloud Logging Application Insights

ユースケース

  • AWS中心の既存基盤 → Lambda
  • BigQuery / Pub/Sub 中心 → Cloud Functions (Gen2)
  • Azure AD / .NET → Azure Functions

サンプル（Python / Lambda）

def handler(event, context):
    name = event.get("name", "world")
    return {"statusCode": 200, "body": f"Hello, {name}"}

まとめ

「どれが最強」ではなく、既存クラウドとチームスキルに合わせて選ぶのが現実的です。次回はコンテナベースの Cloud Run / Fargate との使い分けを整理します。
